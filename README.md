# Vesper

Rappels de pauses pour Windows 11. Ce dépôt ne contient que le programme : `vesper.exe` et `latest.txt` (version et empreinte SHA-256). Le code source est privé.

**Installer** : télécharger [vesper.exe](https://github.com/Eyji/vesper-releases/raw/main/vesper.exe) et double-cliquer dessus. Vesper s'installe dans `%LOCALAPPDATA%\Programs\Vesper`, apparaît dans le menu Démarrer, se lance au démarrage de Windows et se met à jour tout seul.
